# 制作スタジオ：残した案と見比べて、選べる

「色や写真を変えたいが、今の案も捨てたくない」に対応する。比較用の案を1つ残し、編集中の案と実際の完成像で比べて採用できる。

## 操作

1. 編集中に「いまの案を残す」。サイトの文章・写真・設定を複製し、この制作画面のメモリに保持する。保存APIは呼ばない。
2. 通常どおり編集し、「案を見比べる」。PCは横並び、スマホは2案の切り替え。パソコン幅／スマホ幅の切り替えもできる。
3. 「比べる場所」で、両方を同じ節へ移動する。片方にしかない節は、その案に存在しない旨を表示する。
4. 「今の案で続ける」は比較を閉じるだけ。「残した案に戻す」は文章・写真・設定を含むサイト全体を戻す。取り消し履歴にも1手として入るので採用を取り消せる。
5. 現在の案を新しい比較用の案にする場合は、置き換えを確認してから更新する。

比較用の案はタブを閉じる・ページを読み直すと消える。一方、通常の現在の下書きは既存の端末復旧の仕組みを継続する。この違いを画面に明示した。読み込み・初期生成・下書き復旧で比較用の案もリセットし、以前のサイトへ戻れる状態を残さない。

## 表示と実装

トップページの完成像を比較する。画像合成ではなく、それぞれのスナップショットから `exportToHTML` で生成する。140ms遅延する編集用プレビューのHTMLを流用しないので、編集直後に比較を押しても古い内容を比較しない。

差分表示はサイト名、設定、節の追加／削除／内容変更／順序、ページ・検索用情報をデータで照合する。点数や優劣を捏造しない。

比較の目的は静止状態の見た目の確認。生成HTMLの製品スクリプト・インラインイベント・埋め込みフレームを除去し、フォームを無効化する。動画はポスターへ置換する。画像・書体・CSSは実際の指定を使う。sandboxの独立したiframeで親の認証情報やDOMへ触れず、CSPでフォーム送信・接続を禁止し、nonceを付けた節移動のスクリプトだけを許可する。親子の通知はwindowの送信元も照合する。

ネイティブdialogで背面を操作不能にし、比較中は親の編集履歴ショートカットも停止。Escapeで閉じ、起動ボタンへフォーカスを戻す。画像アップロード中は比較の起点作成・起動を待つ。

## 検証環境と限界

本番用ビルド、localhost:3319、Supabase代替 localhost:54999、実ブラウザ。外部タグは遮断し、選択書体は同じ配布フォントをローカルで供給する。写真・保存の実APIはアプリのものを使用し、保存先だけ隔離した代替である。本番・実機Safariの測定ではない。

`tests/browser/studio-comparison-check.mjs` は320/390/1440pxで、起点保持、直前の編集の反映、親DOMの隔離、送信できないこと、節移動、比較画面内のTab移動、Escapeとフォーカス復帰、採用と取り消し、起点の置換、再読み込みでの消去を検査する。

初回の実ブラウザ試験では、DOMParserの文書でscript.nonceへの代入がHTML属性として出力されず、CSPが節移動も拒否していた。setAttributeへ変更し、同じ節へ実際にスクロールできることを再実行で確認した。CSPの制限を緩めて回避してはいない。

公開HTMLの生成本体、保存API、公開API、DB、決済、独自ドメインには変更なし。push・デプロイ・SQL適用・本番再生成・追加の素材生成は実施しない。
