# Higgsfield 素材制作指示 — 結い庵とLaruVisona

目的: Codex監督・Claude実装で進めるサイト刷新の画像素材をまとめて用意する。サイト構築・デプロイはしない。

初回制作は7枚。結い庵のスタイル4枚、架空スタッフ3枚。参照はyuian-hero-B.png。既存店内の窓・鏡・家具・自然光の色を基準にするが、ヘア写真は主に髪が見える淡い左官壁の背景とし、空間の矛盾を増やさない。

スタイル4枚（各4:5、可能なら1200×1500以上）:
1. ダークブラウンのボブ。後ろ斜めから。毛先の形と自然なツヤ。
2. 肩下のミディアムレイヤー。横〜後ろ斜め。動きが見える。
3. 短いショート。横〜後ろ斜め。後頭部と襟足の形。
4. 白髪を自然に活かした大人のミディアム。後ろ斜め。過剰な若返り表現なし。

髪の毛束の連続性・耳/首/肩・服の形を確認。濡れ髪や作り物の光沢、広告文字、ブランドロゴ、コラージュ、before/afterを入れない。顔を完全に隠すために不自然な首の向きにせず、顔が主役にならない自然な角度にする。

架空スタッフ3枚（各1:1、可能なら600×600以上）:
- 成人の女性店主、成人の男性スタイリスト、成人の女性スタイリストの3人。
- 実在人物を指定しない。自然な笑顔、清潔な無地の服、淡い左官壁。全員同じ光・距離・色調。
- 胸から上、頭頂/肩に円形切抜き用の余白。手を無理に入れない。
- 架空店舗の生成イメージとして公開側で明示する。実在社員/顧客の実績として扱わない。

実行前にモデルと7枚の見積もりを取得。初回の提案上限は合計100クレジット。ユーザーがこの指示で実行を依頼した場合、上限内なら進め、上限超過なら生成前に金額を示す。追加生成/動画化/有料アップスケールは別。既存Plusの無制限枠を自動化で迂回しない。

出力名: style-1〜4、staff-1〜3。画像を会話内に並べ、利用できるファイルリンク、モデル、実消費クレジット、参照画像の使用有無を報告。画像からサイトの文字や実際の予約UIを生成しない。

後続（今回の7枚に混ぜない）:
会社サイトの抽象的なブランド画像を1点検討。深いネイビー/インク、抑えた青とシアン、過剰な発光やロボットの顔は不要。実製品画面はClaudeの実装後に撮影する。LARUHPのLPでは実作品と実画面を主役にし、抽象画像を必須にしない。
