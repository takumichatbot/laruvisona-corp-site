# 既存ホームページの移行診断

既存ホームページから LARU HP へ移る前に、移行元を壊さず内容を棚卸しできる入口を追加した。

## 今回できること

- 入力されたURLと同じサイト内を最大8ページまで確認する。
- ページごとのURL、タイトル、説明文、H1、画像数と、サイト全体の不足件数を表示する。
- 複数ページの本文から店舗・会社名、連絡先、説明、サービス、営業時間を下書きへ移す。
- 内部アドレス、ログイン・管理画面、外部サイト、HTML以外のファイルは巡回しない。
- 取得した文章は命令ではなく資料としてAIへ渡し、確認できない実績・数字・口コミ・資格を作らせない。

この段階では移行元サイトへ書き込まず、画像、既存URL、検索設定も変更しない。

## 次の段階

移行を完成させるには、診断結果を基に次を利用者が確認してから実行する。

1. 旧ページと新ページの対応、残すURLと転送先
2. 利用権限を確認した画像の複製と代替文
3. title、description、canonical、構造化データの比較
4. 問い合わせ、予約、ブログ、商品など動的機能の置き換え
5. プレビュー承認、独自ドメイン切替、旧URLの転送、切り戻し

旧サイトを止めるのは、新サイトの表示、フォーム、検索設定、URL転送を確認した後に限る。

## 検証

- HTMLからSEO・本文・画像を抽出する。
- 巡回は同一originの公開HTMLだけに限定し、クエリと断片を除く。
- 途中ページが取得できなくても診断全体を失敗させず、上限8ページで止める。
- 同一originの制限を外す負の対照で回帰が失敗することを確認した。
