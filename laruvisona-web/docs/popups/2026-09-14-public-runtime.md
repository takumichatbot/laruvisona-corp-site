# ポップアップ公開動作

管理画面で保存できる設定と、公開サイトでの実際の動作を一致させた。

- 最大表示回数と非表示期間を、サイトIDとポップアップIDごとの端末内記録で判定する。
- 同じ閲覧中は1件だけを表示し、複数設定では最初に条件を満たしたものを出す。
- `javascript:`、`data:`、プロトコル相対URL、平文HTTPをリンク先にしない。
- 公開前・壊れた設定・長すぎる文字・不正な色と数値を配信しない。
- ダイアログの役割と名前、Escape、Tabの循環、閉じた後のフォーカス復帰を実装する。
- DB照会の失敗を「設定なし」に変えず503にする。
- 公開サイト側が自動で読み込むため、利用者へ手動のscript貼り付けを案内しない。
