# 共通部分（フォント・CSS・gtag）の実測結果

計測日: 2026-09-10。本番 laruvisona.jp を Chrome の Performance API で計測。
バイト数は、そのURLを取り直して実際の長さを測った値（キャッシュ状態に依存しない）。

## 結論: 3件のうち2件は同じ原因、1件は誤りだった

### 1. gtag の重複 — **誤報だった。訂正する**

前回「gtag が1ページで2回リクエストされている」と報告したが、実測すると重複ではない。

| 計測項目 | 値 |
|---|---|
| `googletagmanager` のリソースエントリ | 2 |
| うち initiatorType | `link`（preload、102ms）と `script`（6ms） |
| `<script src>` の実タグ数 | 1 |
| `gtag('config', ...)` の呼び出し | 1 |
| `page_view` の重複 push | 0 |

`next/script` の `afterInteractive` が preload を出し、その後スクリプトが
キャッシュから読まれている。ダウンロードは1回。**修正不要。**

### 2 と 3. CSS 284KB と フォント — **同じ1行が原因**

`app/layout.tsx` の

```ts
const notoSansJP = Noto_Sans_JP({ subsets: ['latin'], weight: ['400','500','700'] });
```

日本語は文字数が多いため、`next/font/google` はウェイトごとに100個以上の
`@font-face`（unicode-range 付き）を生成する。その宣言だけで CSS が 284KB になり、
**サイトの全ページに配られている**。

| ページ | リクエスト数 | woff2 ファイル | フォント計 | CSS計 | body の第1フォント |
|---|---|---|---|---|---|
| 会社トップ `/` | 66 | 38 | 743 KB | 510 KB | Noto Sans JP |
| 認証画面 `/laruHP/auth/login` | 37 | 12 | 270 KB | 510 KB | Noto Sans JP |
| 既存LP `/laruHP` | 79 | 47 | 934 KB | 510 KB | Noto Sans JP |
| 新LP `/laruHP/lp-next` | 21 | 2 | 47 KB | 510 KB | Noto Sans JP（実際に使われた face は 0） |

CSS 510KB の内訳は 284KB（@font-face 宣言）＋ 225KB ＋ 1.3KB。
284KB の1本が、どのページでも描画をブロックしている。

新LP は `.font-system-jp` で端末のフォントを使うので、実際に使用された
`@font-face` は 0 だが、**preload された woff2 2ファイル 47KB は無駄に落ちている**。

ダッシュボード（要ログイン）と顧客公開HP `/hp/<slug>` は、
どちらも `app/layout.tsx` の配下なので同じ CSS 284KB を受け取る。
顧客公開HPは本番に公開中のサイトが見つからなかったため直接は計測していない
（sitemap に `/hp/` のURLが無い）。ここは未計測として残す。

## 選択肢

| 案 | 効果 | 影響 |
|---|---|---|
| A. ルートレイアウトの Noto Sans JP をやめ、`.font-system-jp` と同じ端末フォントを全サイト既定にする | 全ページで CSS −284KB。会社トップ −743KB、既存LP −934KB、認証画面 −270KB | **会社サイト・管理画面・顧客HPの日本語書体が全部変わる**。デザインの判断が要る |
| B. `preload: false` だけ付ける | 新LPから 47KB・2リクエストが消える。CSS 284KB は残る | フォントを実際に使うページで読み込みが少し遅れる（FOUT が長くなる可能性） |
| C. 何もしない | — | — |

推奨は A。ただし書体が変わるのは見た目の判断なので、こちらで勝手に入れない。
A を進める場合は、会社トップ・認証画面・ダッシュボード・顧客HPの
変更前後のスクリーンショットを出してから切り替える。

B は単独でも入れられるが、得られるのは新LPの 47KB だけで、
284KB の本体には効かない。A の判断を待つほうが筋がよい。
