# 15の業種ページに、その業種の人にしか書けないことを書いた（2026-09-17）

## 何が問題だったか

本番の15ページを機械で突き合わせた。

```
平均一致率        76%（最大 81%：/beauty と /pet）
1ページの文字数   約700字（ナビ・フッター込み）
業種ごとに違う行  57行中 11行
実質ユニーク      1ページあたり およそ150字
```

その11行の中身は、業種名の繰り返し・キャッチ1行・説明1段落・掲載項目3つ・
注意書き3つ。**型紙の穴埋めを15枚並べていた。**

市区町村ページを量産しないと決めたのと、軸が違うだけで同じ形である。
新しいドメインで、ほぼ同一の薄いページを15枚sitemapに載せている状態は、
順位に効かないどころかサイト全体の評価を下げる。

## 何を足したか

`lib/laruhp-industry-detail.ts` に、その業種の人にしか書けないものだけを
入れた。15業種すべてに、以下の5つ。

| 項目 | 中身 |
|---|---|
| `problems` | その業種でよく起きる困りごと3つと、なぜ起きるか |
| `musts` | 載せる情報4〜6点と、**載せる理由** |
| `inquiry` | 問い合わせ・予約が実際どう来るか、何を設計するか |
| `firstStep` | はじめの一歩3つ。この順でやれば形になる |
| `rules` | 公開前に自分で確かめる決まりごと3つ（根拠の名前つき） |
| `faq` | その業種の人が実際に聞くこと3つ |

結果、**業種固有の文章は1ページあたり150字 → 900〜1,100字**になった。

例（抜粋）。

- 飲食：「今日やってますか」の電話が営業中に鳴る／食品表示法のアレルゲン
- 美容：掲載サイトの送客手数料／薬機法にあたる効果表現
- 不動産：徒歩時間は道路距離80m＝1分（公正競争規約）／おとり広告
- ペット：第一種動物取扱業の登録番号の表示
- 歯科：自由診療は費用・回数・期間・主なリスクを1組で
- フィットネス／学習塾：特定継続的役務提供にあたるかの確認
- ホテル：自社の予約導線を、外部予約サイトより目立つ位置に

## 決まりごとの扱い

`rules` は**法的な助言ではない**。「この決まりがあるので、自分の内容を
照らし合わせてください」という確認項目である。画面にもそう書いた。

> 法的な助言ではなく、自分の内容を照らし合わせるための一覧として置いています。
> 判断に迷うときは所管の窓口やその分野の専門家にご確認ください。

検査でも、この2文が画面から消えていないことを見ている。

## 検索側への効き方

- **説明文（meta description）も業種ごとに変えた。**
  以前は「{業種名}に必要なページ構成と…」の型で、15件が検索結果で同じ顔になっていた
- **FAQを構造化データ（FAQPage）にも出した。**
  困りごとのページ（`/trouble`）と同じ作りで、検索結果に質問が並ぶ可能性がある

## 再発防止

型紙に戻ると誰も気づかないので、検査で縛った。

- 公開している15業種すべてに中身がある（`LARUHP_INDUSTRIES` と突き合わせ）
- 量がそろっている（困りごと3・載せる情報4以上・決まりごと3・FAQ3・はじめの一歩3）
- **業種固有の文章が900字以上あり、どの2業種の一致率も45%未満**
  （4-gramで総当たり。以前は平均76%だった）
- 決まりごとは根拠の名前つきで、確認の形になっている
- 法的な助言ではない旨が画面にある
- FAQが構造化データにも出ている
- 説明文が業種ごとに変わる作りになっている
