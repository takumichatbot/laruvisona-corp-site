# 定期メールの配信台帳

週次レポートと契約後の案内メールを、`hp_scheduled_email_deliveries` の排他台帳へ統一した。

- 同じ利用者・種類・期間は一意で、複数の実行元が同時に動いても1件だけを取得する。
- 取得には10分の期限があり、停止した処理は回収できる。送信試行は最大5回。
- Resendにも台帳ID由来の冪等キーを渡す。送信後に応答が失われても重複を抑える。
- 週次の訪問数は `daily_views` の直近7日とその前の7日を合計する。累計値への置換はしない。
- 旧週次エンドポイントも同じ処理へ委譲し、二重配信を防ぐ。
- 利用者はアカウント設定から週次レポートを停止できる。

適用するSQL: `supabase/hp_scheduled_emails.sql`
