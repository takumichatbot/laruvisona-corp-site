# 素材の依頼書 — 会社トップ（2026-09-12 版）

実装は素材待ちで止めていません。いまは下の「仮で使っているもの」で成立しています。
届いたら差し替えるだけの状態です。**金額の上限はこちらで推測しません。**

共通の決めごと

- 金属・鉄・クロームは使わない。水、透明なガラス、柔らかな光、奥行き。
- 青はブランドの範囲（`#0EA5E9` 〜 `#BAE6FD`）に寄せる。地は深い紺〜黒（`#04080f`）。
- **画像の中に文字・UI・数値・ロゴを描かない**。文字はすべてHTMLで載せます。
- 粒の並びをロゴとして見せる場合は、`public/images/laruvisona_mark.svg` の座標に従う。
  生成画像を目測でトレースしない。
- 納品形式：WebP（品質80前後）。原画（PNG）も併せて保存。生成記録（モデル・入力・プロンプト）も残す。
