# 制作入口の一本化（2026-09-14）

## 問題

新しい制作スタジオを実装した後も、登録完了メール、料金、紹介URL、ダッシュボード、コマンド検索、旧デモは `/laruHP/onboarding` と `/laruHP/builder` を案内していた。利用者は入口によって別の制作体験へ入り、旧ウィザードの絵文字中心の画面と、新スタジオの「きく・えらぶ・ととのえる・出す」が混在していた。

## 変更

- 新規作成と通常の既存サイト編集は `/laruHP/studio` を正規入口にした。
- `/laruHP/onboarding` は公開済みURLの互換用に残し、`industry`、`mood`、紹介者IDだけを新スタジオへ渡して即時転送する。旧画面自体は配信しない。
- 新スタジオが紹介者IDを登録まで端末内に保持する。別の任意パラメータは持ち込まない。
- 新規登録、紹介URL、料金表、公開デモ、ダッシュボード、代理店画面、分析画面、メール内の通常編集リンクをスタジオへ統一した。
- 旧ビルダーは、スタジオ内の「これまでの編集画面」と旧ビルダー固有の詳細設定だけに残した。既存URLと操作を急に消さない。

## 検証

- 旧URLが許可した入力だけを保ってスタジオへ転送することを回帰にした。
- 登録、紹介、ダッシュボードの正規入口と、紹介者IDが登録画面まで保持されることを固定した。
- 新スタジオの作成・下書き・編集・公開に関する既存回帰を再実行する。

本番変更とpushは行っていない。
