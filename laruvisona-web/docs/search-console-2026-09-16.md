## インデックスの状況

- 登録済み: 9ページ
- 未登録: 8ページ（404が2、クロール済み-インデックス未登録が6）

**「クロール済み - インデックス未登録」の6件は、全部ページではなかった。**

```
favicon.ico?favicon.0t62kbk~klanh.ico
favicon.ico?favicon.01o-65sp.01ux.ico
favicon.ico?favicon.0x3dzn~oxb6tn.ico
/manifest.json
/laruHP/opengraph-image
/laruHP/privacy
```

faviconとmanifestは、Googleがそもそもインデックスしない種類のもの。
**中身のあるページが「価値なし」と判断された形跡は無い。**
これは良い知らせで、今回作った14本も普通に載るはずだということ。

## 404が2件あった（直した）

```
https://laruvisona.jp/index.html   前回クロール 2026/09/04
https://laruvisona.jp/terms.html   前回クロール 2026/07/06
```

旧サイトの名残。9月に入ってもまだクロールされている＝どこかから
リンクが残っているか、Googleが覚えている。消えるのを待つより、
今のページへ送ったほうがその分を拾える。

`next.config.ts` に恒久リダイレクトを追加した。
`/privacy.html` も同じ理由で予防的に入れてある。

```
/index.html    → /         (308)
/terms.html    → /terms    (308)
/privacy.html  → /privacy  (308)
```
