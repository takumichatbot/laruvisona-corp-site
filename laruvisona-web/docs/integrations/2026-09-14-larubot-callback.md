# LARUbot連携IDの書き戻し（2026-09-14）

LARUbotが発行した公開IDをLARU HPへ返すWebhookを、Cookieに依存しないサーバー間処理に直した。

- `x-laru-secret` が一致した後だけservice roleを使う。
- 利用者ID、任意のサイトID、公開IDの形式を検査する。
- サイト指定時は `site_id` と `user_id` の両方が一致する行だけを更新する。
- 全サイトへの書き戻しでも、各更新を `user_id` で再度絞る。
- 読み取り失敗、不存在、更新失敗、更新0件を成功として返さない。

本番では、LARUbot付きプランのテスト契約から登録を1回行い、対象利用者の対象サイトだけに公開IDが入り、公開HTMLへ正しい埋め込みが出ることを確認する。
