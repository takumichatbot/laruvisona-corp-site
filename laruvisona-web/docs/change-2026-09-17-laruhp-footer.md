# LARU HPの公開ページに、出口を付けた（2026-09-17）

## 見つけ方

本番の28ページについて、どこへリンクしているかを数えた。

```
/                      運営会社・ガイド・問い合わせ・規約・プライバシー・特商法  … 6本
/beauty など15業種      料金・ガイド・問い合わせ・プライバシー                 … 4本
/plans                 自分自身のみ                                          … 0本
/contact               自分自身のみ                                          … 0本
/domains               自分自身のみ                                          … 0本
/tokusho /terms /privacy   「トップに戻る」だけ                               … 1本
/articles /articles/*  記事どうしのリンクのみ
```

**まともなフッターがあるのは、28ページのうちトップの1ページだけだった。**

とくに悪かったのが2つ。

- **`/plans` から、規約にも特商法にも問い合わせにも行けない。**
  いちばん買う直前のページに、出口が無かった。
- **運営会社（laruvisona.jp）へのリンクが、28ページ中1ページにしかない。**
  カード情報を入れるか決める材料が、ほとんどのページに無い。

3つ目として、内部リンクの無いページには検索側の評価も伝わらない。
会社サイトの `/works` が「参照元ページ: 検出されませんでした」だったのと
同じ形が、LARU HP側でも起きていた。

## 直したこと

`components/laruhp/PublicFooter.tsx` を作り、公開ページ9種すべてに付けた。

| 列 | 中身 |
|---|---|
| サービス | LARU HPについて／料金プラン／独自ドメイン／作成ガイド／お問い合わせ |
| 規約・表記 | 利用規約／プライバシーポリシー／**特定商取引法に基づく表記** |
| 運営 | **株式会社LaruVisona**／開発実績／受託開発 |
| 業種から探す | 15業種すべて |

付けた先: `[industry]` `plans` `domains` `contact` `articles` `articles/[slug]`
`terms` `privacy` `tokusho`。トップは自前の大きなフッターを持つのでそのまま。

暗い配色のページ（特商法・規約・プライバシー・業種ページ）には `dark` を渡す。

## 効くところ

1. **申し込みの手前から、規約・特商法・運営会社へ行ける**
2. **15の業種ページが、どのページからも1クリックで辿れる**
   検索側から見て、15枚が孤立していない
3. **2つのサイトが互いを補強する**
   laruhp.com → laruvisona.jp（運営会社・実績・受託）の導線ができた

## 再発防止

ページを足したときにフッターを忘れる、が起きやすいので検査で縛った。

- 公開ページ9種すべてが `PublicFooter` を使っている
- フッターに規約・プライバシー・特商法・運営会社のリンクがある
- 業種は一覧を `LARUHP_INDUSTRIES` から回している（手書きしていない）
- 15業種すべてに表示名がある
- フッターの案内先が、公開パスの一覧（`LARUHP_PUBLIC_PATHS`）と食い違っていない
