# AI原価と素材生成の境界

利用者向けAI APIは、有効なLARU HP契約とDB共有の時間枠を必要とする。文章系は複数画面を合わせて1時間30回、サイト一括文章は1時間20回、節の提案は1時間12回、画像生成は1時間3回までとする。複数のRenderインスタンスでも同じ `hp_ai_usage` を使うため、プロセス再起動や別インスタンスで回数は戻らない。

業種別の画像ライブラリは事前生成素材である。公開 `GET /api/library-image` と利用者の初回制作は、素材が無い場合に外部画像生成を起動しない。追加制作は認証済みの管理者経路で内容と費用を確認してから行う。

この制限は原価保護であり、生成内容の正しさを保証するものではない。文章生成には別途、未確認の実績・価格・体験談を作らない境界を適用する。
