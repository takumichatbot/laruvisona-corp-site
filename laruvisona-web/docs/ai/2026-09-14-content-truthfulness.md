# AI下書きの事実境界

AI一括生成と節ごとの文章生成は、利用者が入力した事業情報を引用データとして扱う。入力中の命令には従わず、入力にない実績、数字、価格、資格、受賞、保証、所在地、営業時間、人物、評価、顧客の声を作らない。

生成APIは体験談と実績欄を返却時にも空にする。旧オンボーディングが残す保存済みAIデータからも、体験談と「3つの根拠」を自動挿入しない。体験談は実在する本人の確認済み内容を利用者が自分で入力する。

新規サイトは旧テンプレート経路でも制作スタジオと同じ安全化処理を通す。架空の人物は除外し、料金・サービス例は「【例】」「入力してください」表示で公開前確認の必須項目に残す。
