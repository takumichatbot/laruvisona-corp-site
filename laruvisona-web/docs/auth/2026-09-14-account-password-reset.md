# 管理者アカウントのパスワード再設定

独自HMACリンクと管理APIによる直接更新を廃止し、Supabase Authの回復セッションへ統一した。

- 公開APIで全利用者を列挙しない。登録済みかどうかにかかわらず同じ成功応答を返す。
- 同一IPから1時間5回に制限する。
- 回復リンクは `auth.admin.generateLink({ type: 'recovery' })` で発行する。
- リンク先のcallbackでSupabaseのcodeを回復セッションへ交換する。
- 新しいパスワードは、その回復セッションを持つブラウザが `auth.updateUser` で設定する。
- `ADMIN_SECRET` 未設定時の固定文字列、URL上の独自トークンとメールアドレス、管理APIによるパスワード直接更新を使わない。
- メール未設定・外部送信障害・未登録アドレスを公開応答から区別できないようにする。運用ログにはメールアドレスを残さない。
