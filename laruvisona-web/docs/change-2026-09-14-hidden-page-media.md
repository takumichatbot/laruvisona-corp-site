# 複数ページの非表示メディアを先読みしない

## 問題

複数ページ形式の公開HTMLは、2ページ目以降を `hidden` で開始する。一方、各ページの写真つきヒーローは一律 `loading="eager" fetchpriority="high"` だったため、訪問直後には見えない下層ページの写真まで先に取得していた。

## 変更

- 最初に見える1ページ目のヒーローだけを eager/high にする。
- 2ページ目以降のヒーローとスマホ用の補助写真は lazy にする。
- ページを開いた時点でブラウザの遅延読み込みが取得を開始するため、画面遷移の仕組みは変えない。
- `EXPORT_VERSION` を16から17へ更新する。保存済みHTMLの一括再生成は行わない。

## 検証

1ページ目のスタッフ写真、2ページ目の写真つきヒーロー、2ページ目の通常画像を同じ生成HTMLへ入れ、優先画像が常に1枚だけであることを固定する。
