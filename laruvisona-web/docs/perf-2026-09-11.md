# 初回表示の計測 — 2026-09-11（rev2レビュー後に追記）

> **この数字の範囲。**
> ローカルの隔離環境で、外部の計測タグを遮断し、会社トップの主役素材が
> まだ入っていない状態の値。**本番全体がこの速さだという意味ではない。**
> 「何を直したら、どれだけ縮んだか」を見るための比較値として扱う。
> 親ページのLCPは、デモの中の写真が出た時刻でもない（下の「デモの中の時刻」）。


前回（2026-09-10）は、自社の2ページが回線とCPUを絞った条件で 3.9〜4.0秒だった
（目安 2.5秒）。原因を数字で切り分けて直し、同じ条件で測り直した記録。

## 測り方（前回と同じ条件）

- ローカルの隔離環境。`npx next build` → `npx next start`
- 毎回まっさらな入れ物（キャッシュ・保存領域なし）で3回、その中央値
- 外部の計測タグ（GA・Clarity・LARUbot）は遮断
- 絞った条件: **1.6Mbps・遅延150ms・CPU 1/4**
- PC 1440×900 dpr1 / スマホ 390×844 dpr2
- 道具: `docs/reference-sites/salon/perf-check.mjs`（`--slow yes` で絞る）

目安: LCP 2.5秒以内 / CLS 0.1以下

## 原因の内訳

描画をせき止めるCSSが、`/` と `/laruHP` で3本・合わせて490KB（転送130KB）あった。
内訳を実測すると、いちばん大きい1本が **292KB（転送102KB）で、中身は
Noto Sans JP の `@font-face` 宣言だけ**だった。

| ファイル | 生 | 転送 | 中身 |
|---|---|---|---|
| （フォント） | 292KB | 102KB | Noto Sans JP の `@font-face` **372個**（124の文字範囲 × 3つの太さ） |
| （Tailwind・globals） | 196KB | 28KB | 画面の見た目 |
| （その他） | 2KB | 0.6KB | — |

日本語は文字が多いので、`next/font` は「使う文字の範囲ごとに分けた宣言」を
全部書き出す。`subsets: ['latin']` を指定しても、この家族では124個の範囲が出る。
**フォントのファイル自体は、その文字を使うまで落ちてこない。** 落ちてくるのは
この宣言のCSSだけで、それが描画をせき止めていた。

## 直したこと

1. **日本語のwebフォントを配るのをやめた**（`components/BrandFonts.tsx`）。
   日本語は端末に入っている書体で組む（Apple はヒラギノ角ゴ、Windows は游ゴシック、
   Android は Noto Sans CJK）。0バイト。
   英字の見出しだけ Space Grotesk を読む（latin のみ・数KB）。
   → 描画をせき止めるCSSが 130KB → 28KB（転送）になった。
2. **組立デモの高さを、読み込む前から決まる形にした**（`aspect-ratio` をCSSで与える）。
   高さを測ってから広げていたので、写真が届くたびに下の内容が動いていた。
3. **「組み上げる／もう一度ばらす」ボタンの幅を固定**した。文言で幅が変わり、
   押した瞬間に周りが動いていた。
4. **ばらけているときの引き**を、外側の枠ではなく入れ物の中でかけるようにした。
   外でかけると、外のページの並びが動いたことになる。

## デモの中の時刻（親ページのLCPとは別に測る）

案内ページの主役は組立デモなので、「枠が置かれるまで」「中の写真が出るまで」
「触れるようになるまで」を別に記録する。
道具: `docs/reference-sites/salon/demo-timing-check.mjs`

測り方は、入れ物の中にも計測用のスクリプトを入れ、区切りごとに親へ知らせて
**親の時計**で時刻を取る。外から覗く形にすると、CPUを絞った条件では覗く動作
そのものが重く、3つの時刻が同じ値に丸まってしまう。

### 絞った条件（1.6Mbps・150ms・CPU 1/4・3回の中央値）

| | PC | スマホ |
|---|---|---|
| 親ページの初回表示（LCP） | 1.18秒 | 1.09秒 |
| デモの枠が置かれるまで | 2.31秒 | 1.99秒 |
| **デモの写真が出るまで** | **2.76秒** | **2.40秒** |
| **デモが触れるようになるまで** | **3.01秒** | **2.69秒** |

### 絞らない条件

| | PC | スマホ |
|---|---|---|
| 親ページの初回表示（LCP） | 0.22秒 | 0.16秒 |
| デモの枠が置かれるまで | 0.31秒 | 0.27秒 |
| デモの写真が出るまで | 0.41秒 | 0.36秒 |
| デモが触れるようになるまで | 1.01秒 | 0.97秒 |

デモは「画面に近づいてから作る」作りなので、枠が置かれるのは親の表示より後になる。
触れるまでに差があるのは、ばらけた状態を見せてから組み上げているため（意図的に
0.7秒待ってから動かす）。

**素材（会社トップの主役静止画・動画、結い庵の写真）が入ったら、同じ条件で
測り直してこの表を更新する。**

## 顧客の選択書体を含めて測り直す（2026-09-11 追記）

ここまでの数字は、外部の書体（Google Fonts）を遮断して測っていた。
結い庵は顧客の設定で明朝（Shippori Mincho）を選んでいるので、
**その書体が落ちてくる条件でも測り直した。**

この環境は外へ出られないので、手元に取ってある同じCSS・同じ woff2 を
127.0.0.1 から返している（実物と同じファイル。日本語の明朝は1書体1.4MB）。

```bash
node docs/reference-sites/salon/perf-check.mjs --url <URL> --slow yes \
  --font-css /tmp/salon/mincho-real.css --font-dir <shippori-mincho の woff2 置き場>
node docs/reference-sites/salon/demo-timing-check.mjs --url <URL> --slow yes \
  --font-css ... --font-dir ...
```

### 親ページの初回表示（1.6Mbps・150ms・CPU 1/4・3回の中央値）

| ページ | | 書体を含まない | **書体を含む** | 目安 |
|---|---|---|---|---|
| 会社トップ | PC | 1.16秒 | **1.14秒** | 2.5秒 |
| 会社トップ | スマホ | 1.11秒 | **1.14秒** | 2.5秒 |
| LARU HP 案内 | PC | 1.13秒 | **1.16秒** | 2.5秒 |
| LARU HP 案内 | スマホ | 1.09秒 | **1.06秒** | 2.5秒 |
| 結い庵（顧客サイト） | PC | 1.64秒 | **1.75秒** | 2.5秒 |
| 結い庵（顧客サイト） | スマホ | 1.61秒 | **1.91秒** | 2.5秒 |

CLS は 0.0000〜0.0265（目安 0.1）。

顧客の書体は `font-display: swap` で読むので、最初の描画は端末の書体で出て、
届いたら差し替わる。LCPが大きく動かないのはそのため。
自社の2ページは和文をwebフォントで配っていないので、ほぼ変わらない
（デモの中の公開HTMLだけが明朝を読む）。

### デモの中の時刻（書体を含む・同条件）

| | PC | スマホ |
|---|---|---|
| 親ページの初回表示（LCP） | 1.18秒 | 1.10秒 |
| デモの枠が置かれるまで | 2.37秒 | 2.06秒 |
| **デモの写真が出るまで** | **2.99秒**（含まない時 2.76秒） | **2.55秒**（2.40秒） |

書体を含めると 0.1〜0.25秒ほど遅くなる。デモの中は明朝を読むため。

## 残したこと（判断が要る）

- **日本語の書体**。いまは端末の書体で組んでいる。Windows の游ゴシックは
  細めなので、Noto Sans JP と印象が変わる。どうしても揃えたい場合は、
  使う文字だけを切り出した1ファイルを自分で作って持つ形になる
  （必要な文字が決まる＝文言が固まってからでないと作れない）。
  今回は「2.5秒に入らない」ほうを重く見て、端末の書体にしてある。
- Tailwind の28KB（転送）はそのまま。ここは描画をせき止めるが、
  上の変更で全体が目安の内側に入ったので、今回は触っていない。


## 素材を入れて測り直す（2026-09-11 追記）

会社トップの主役静止画（`public/brand/hero-*`）を入れた状態で、同じ条件
（1.6Mbps・150ms・CPU 1/4・顧客の選択書体を含む・3回の中央値）で測り直した。

| ページ | | 素材なし | **素材あり** | 目安 |
|---|---|---|---|---|
| 会社トップ | PC | 1.20秒 | **1.23秒** | 2.5秒 |
| 会社トップ | スマホ | 1.16秒 | **1.19秒** | 2.5秒 |

LCPの対象は、素材なしでは見出し（H1）、素材ありでは主役の画像。
画像は avif で 7KB（PC 640幅）／5KB（スマホ 420幅）が選ばれている。
場所は縦横比で先に取っているので CLS は 0.0000 のまま。

### LARU HP 案内（デモを作り替えたあと）

| | PC | スマホ |
|---|---|---|
| 親ページのLCP | 1.24秒 | 1.22秒 |
| デモの枠が置かれるまで | 2.44秒 | 2.16秒 |
| デモの写真が出るまで | 2.96秒 | 2.60秒 |
| デモが触れるまで | 3.35秒 | 2.71秒 |
