# 旧決済リンクの移行

旧 `/api/stripe/payment-link` はLaruVisonaのプラットフォーム口座にPayment Linkを作り、店舗の注文・在庫・通知・返金台帳を通らなかった。新規作成を終了し、販売はStripe Connectを使うショップへ統合した。

既存リンクは削除しない。旧決済リンク画面でURLを確認でき、停止時はStripe側の無効化に成功してからローカル一覧から外す。Stripe側の失敗、サイト設定の同時更新、更新0件はいずれも成功表示しない。

出荷前に本番の `settings_json.payment_links` 件数を読み取りで控える。該当がある場合は利用者へ移行を案内し、入金・返金の整理が済むまで旧リンクを一括停止しない。
