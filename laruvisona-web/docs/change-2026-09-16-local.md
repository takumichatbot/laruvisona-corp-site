# 地域ページを1本だけつくる（2026-09-16）

ブランチ: `company-customers-2026-09-16`（続き）

## 全国の市区町村ぶんを作らない理由

Googleのスパムポリシーが、その形を名指しで挙げている。

> 特定の地域や都市をターゲットとする複数のドメイン名やページを用意し、
> ユーザーを1つのページに誘導する
> — 誘導ページ（Doorway abuse）の例

さらに「大量生成コンテンツの不正使用（Scaled content abuse）」にも、
地名だけ差し替えた実質同一のページの量産が当たる。

罰はそのページに留まらない。サイト全体の評価が下がるので、
困りごとページ7本も一緒に沈む。1,700市区町村ぶんを作るのは、
最も効率よく自分のサイトを殺す方法になる。

出典: https://developers.google.com/search/docs/essentials/spam-policies

## 1本なら効く

地域ページが効くのは、そこにしか書けないことがあるときだけ。
LaruVisona には3つある。

- 本店が板橋区にある
- 導入先（日本エンドレス）も板橋区の会社
- 会いに行ける距離にいる

どれも他の市区町村のページには書けない。だから1本で厚く書く。

## 作ったもの

`/local`

- 見出しは「近いので、会いに行けます。」
  地域名の羅列ではなく、地域が理由になっていることを先に言う
- 日本エンドレスを、同じ地域の会社として紹介
- お伺いできる範囲を8区市で明示（相談・見積は無料）
- 範囲外の人には「無理にこちらで受けるより近くを探したほうがよい場合もある」と書いた。
  これは正直さの話であると同時に、合わない問い合わせを減らす仕掛けでもある
- 困りごとページ4本への内部リンク
- 会社情報（会社名・所在地・代表・事業内容）
- `Organization` + `PostalAddress` + `areaServed` の JSON-LD

これまで会社サイト側には所在地の記述も構造化データも無く、
住所は `/laruHP/tokusho` に1行あるだけだった。
