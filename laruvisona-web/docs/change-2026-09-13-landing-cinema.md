# LARU HP — 映像と立体で完成像を見せる

対象は `/laruHP` と共有用OGP。制作・保存・公開・課金・独自ドメインのコードは変更しない。

## 変更

- コピーを「その仕事に、ふさわしいホームページを。」に統一。制作CTAは「完成を見ながら、つくる」。価格・契約条件は引き続き `laruhp-facts.ts` の値。
- Higgsfieldで制作した青い流れの動画を、HTMLの文字と立体表示の背景へ。原画に文字やUIを入れない。
- 4業種の実際の `exportToHTML` 出力から撮影した画面を、WebGLの3面に分けて表示。スクロールまたはボタンで分解・組立する。これは閲覧用の演出であり、下段の実際に操作できる `CreationLab` とは役割が異なる。
- 古いPCヒーロー用のgrid規則が新しい外枠にも当たり、コピーと画面が細くなる不具合を目視で発見。外枠をblockに固定し、新しい子gridを使う。PCの両列の実寸も回帰へ追加。
- 写真のURLはv2に変更。元のv1配信ファイルを保持し、キャッシュで旧画像が混ざるのを避ける。
- OGPにも同じコピーと動画の静止画を使用。旧コピーと固定のプラン価格一覧は撤去。

## 映像の記録

`docs/asset-source/laruhp-film-20260913/manifest.json` に指定・実返却モデル、プロンプト、ジョブ、消費、原本保存先、配信寸法とバイト数を記録。

- 指定・完了とも MiniMax H3 / `minimax_h3`。6秒・2K・16:9を1本。
- 実消費12クレジット、1165→1153。追加生成なし。
- 原本: 2560×1440、6.584秒、1,866,394 B。原本の音声は配信用から除去。
- 配信: 無音H.264、約5.4秒。PC 1440×810 / 586,604 B、スマホ600×800 / 278,251 B。
- WebPポスター35,292 Bを先に表示。3Dライブラリは別読み込み、初期HTMLには動画srcを含めない。
- 最初の6秒から末尾0.6秒を先頭へクロスフェードし、冒頭0.6秒を取り除いたループ。スマホは原本の1080×1440 (x=1000,y=0) を切り抜く。

## 停止と代替表示

- 手動停止で動画とWebGLを同時に止め、スクロール位置・高さ・立体の現在位置を保つ。
- 画面外・非表示タブでは止める。WebGLはdemand描画で画面外の常時ループを持たない。
- `prefers-reduced-motion` では動画を取得せず、3Dも起動せず、完成例の写真を表示。
- Save-Dataでは動画を取得しない。動画再生を拒否された場合もポスターとHTMLが残る。
- WebGL context lossでは3Dを外し写真に戻す。JS無効でもコピー・制作リンク・写真を表示。
- 業種選択は矢印/Home/Endで操作できる。別業種の画像読み込み中はその業種の写真を表示し、textureが揃ってからcanvasへ切り替える。
