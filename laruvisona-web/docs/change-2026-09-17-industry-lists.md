# 3つの業種ページが、別の業種の下書きを出していた（2026-09-17）

## 見つけ方

案内サイトの「始める」が死んでいたのと同じやり方——**本番で押したら何が起きるかを、
最後まで追う**——を、残りの導線にも当てた。

業種ページの「この業種で試す」は `studio?industry=<id>` へ渡す。
受け取る側はこう書いてある。

```ts
const requested = params.get('industry');
const industry = INDUSTRY_CHOICES.some(c => c.value === requested) ? requested! : 'beauty';
```

**知らない業種は、黙って美容室になる。** そこで3つの一覧を数えた。

```
公開している業種ページ        15  LARUHP_INDUSTRIES
制作画面で選べる業種          12  INDUSTRY_CHOICES     ← 3つ足りない
たたき台の見本文がある業種       5  STARTER_EXAMPLES     ← 10 足りない
```

足りなかったのは `hotel` `wedding` `accounting`。

つまり、**旅館の人が `/hotel` で「この業種で試す」を押すと、
髪を切る店の下書きが出てくる。** 式場も、税理士事務所も同じ。
エラーは出ないので、誰も報告しない。ただ帰るだけである。

## 直したこと

### 1. 足りない3業種を、制作画面の選択肢に足した

ラベルは公開ページと合わせた（ホテル・旅館／ウェディング／税理士・会計士）。
`templates.ts` は15業種ぶん持っていたので、たたき台はすでに用意されていた。
選択肢の一覧だけが取り残されていた。

### 2. 見本の文章を、5業種 → 15業種に足した

見本が無い業種は「あなたの屋号／活動している地域／大切にしていることを、
あなたの言葉で。」という汎用文で始まる。業種ページから来た人に、それを
見せていた。10業種ぶん書いた。

```
歯科     しろは歯科クリニック   説明をしてから始める、歯の治療とお手入れ。
士業     みなも法務事務所      むずかしい話を、わかる言葉で。
教室     こはる学習室         解き方より先に、つまずいた場所を見つけます。
ジム     スタジオ しるべ       続けられる量から、はじめる。
写真     写真室 ひなた        その日の空気ごと、写しておく。
ペット   トリミング もこ       その子のペースに合わせて、整えます。
不動産   常盤台不動産         物件より先に、この街の話から。
ホテル   旅宿 みなも          何もしない一日を、ちゃんと過ごす宿。
式場     リトルハウス         呼びたい人だけを呼ぶ、一日のかたち。
税理士   さくら会計事務所      数字の話を、経営の言葉にして返します。
```

### 3. 未契約の人を、ログインではなく新規登録へ

料金ページで「始める」を押して401になる人は、ほとんどが初めての人である。
これまではログイン画面へ送っていた——**持っていないアカウントの入力欄を、
最初に見せていた。**

登録画面へ送るようにした。登録画面には「既にアカウントをお持ちの方は
ログイン」があり、どちらの画面も `redirectTo`（`?checkout=` を含む）を
保つので、戻ってきたところで決済が再開される。

## 再発防止

今日だけで「2つの一覧が食い違う」を4回見つけた
（Organizationの定義、sitemapと実ページ、画面の料金とStripe、そしてこれ）。
一覧が増えるたびに同じことが起きるので、縛る。

- **公開している業種は、すべて制作画面でも選べる**
- 制作画面で選べる業種には、必ずテンプレートがある
- 公開している業種には、見本の文章がある（汎用文に落ちていない）
- 見本の写真が `public/` に実在する
- 見本の屋号が業種どうしで重複していない
- 3つの一覧が同じ15を指している
- 未契約の人を新規登録へ送っている／両方の画面が redirectTo を検証している
