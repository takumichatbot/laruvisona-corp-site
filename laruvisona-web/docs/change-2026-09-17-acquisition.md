# 2026-09-17 集客の入口を3つ足した

いま laruhp.com には検索からの流入がほぼない（Search Console: 追加直後でデータ0、
laruvisona.jp も3ヶ月で表示310回）。広告は使わない前提なので、
**すでにある資産から入口を増やす**方向で3つ足した。

## 1. 料金の見積り `/simulator`

料金ページは5プランを横に並べているだけで、自分がどれに当たるかは読む側が判断する。
実際にいちばん多い止まり方は「結局いくらかかるのか分からない」なので、そこを1画面で終わらせる。

- やりたいこと（チャット／記事／多言語／サイト数／複数クライアント）と、独自ドメインの有無、
  支払い方法を選ぶと、合うプランと**1年目に支払う合計**が出る。登録は不要。
- 判定と金額は `lib/plan-advice.ts` に置き、画面側に条件分岐も金額も書かない。
  テスト（`tests/plan-advice.test.ts`）で固定している。

決めごととして残したこと。

- **初月無料を織り込む。** 月払いの1年目は11ヶ月分。
- **最低利用期間で必ず発生する額を先に出す。** 「初月0円 + 5ヶ月分」を注意書きに出す。
- **チャットが要るだけなら、いちばん安いプランを勧める。** HP+Bot（4,980円）にもチャットは
  付くが、Lite（2,980円）のほうが安い。高いほうを既定にしない。上がる条件は併記する。
- **独自ドメインの費用を合計に混ぜない。** 登録事業者ごとに違うので、こちらが数字を作らない。
  別途かかるものとして言葉で出す。

## 2. よくある質問 `/faq` + 1問1ページ（9本）

LPの折りたたみの中にあるだけだと、
「ホームページ 月額 だけ」「独自ドメイン 引っ越し メール 止まる」のような
答えを1つ探している検索に、長いLPしか返せない。その質問にリンクを貼りたい人も、貼る先を持てない。

- `lib/laruhp-faq.ts` に、質問・結論・3節以上の本文・次に行く先を持たせた。
  金額は `laruhp-facts.ts` から取る（書き写さない）。
- 一覧に `FAQPage`、各ページに `QAPage` の構造化データ。
- 薄いページを量産しないよう、テストで**本文400字以上・節3つ以上・行き先2つ以上**を強制した。

記事（/articles）とは話題を分けている。こちらは「LARU HP の条件」、記事は「ホームページ制作そのもの」。

## 3. 会社サイト → 月額サービスへの出口

laruvisona.jp（受託）に来た人のうち、予算や規模が合わない相手は、そのまま帰っていた。

- 共通フッターに「LARU HP（月額のホームページ制作）」「業種別の見本」を置いた（`?ref=corp`）。
- 困りごとページのうち、**作り直したほうが早いもの8本**にだけ、出口の節を足した（`?ref=trouble`）。
  症状と関係のないページに出すと邪魔になるので、当てはまるものだけに出す。
  対象: site-slow / ssl-warning / wordpress-admin-locked-out / not-in-google /
  mobile-layout-broken / contact-form-not-arriving / vendor-unreachable / server-migration

## ついでに直したもの

- **料金ページのリンクが、案内サイト側で行き止まりだった。**
  `/plans` は laruhp.com でも配信しているのに、ヘッダーの「ログイン」「制作を試す」が
  相対の `/laruHP/...` を指していた。laruhp.com では `/laruHP/*` を配信していないので404。
  絶対URLに直し、テストで戻らないようにした。
- **日本語でない文字の混入を、見る範囲を広げて止めた。**
  「одно一つ」が入りかけた。ハングルだけを見ていたガードに、キリル文字と、
  本文を直接書いているページを足した。
- **経路テストが、古いビルドのサーバーに当たっていた。**
  `tests/http/run.sh` は動いているサーバーを使い回すが、それがいまのビルドとは限らない。
  足したばかりのページが404で返って、原因の分からない失敗になった。
  ビルドIDを突き合わせて、違ったら止めるようにした。
