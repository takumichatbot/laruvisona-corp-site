## 1. 受託の入口（/services）を、比べられる前に比べる軸へ

これまでのヒーローは「つくる・直す・組み込む／AIとモダンWeb技術で、
御社の『困った』を解決します」だった。**どの受託会社とも同じに見える。**

材料はすでにあった。自社プロダクトを作って、課金して、運用している——
これは受託会社の大半が持っていないものである。ところがその話は
4つ下の節にあり、比べられる前に読まれない位置だった。

- ヒーローを「つくって、売って、運用している。」に変更
- **直後に「運用していないと、気づけないこと」を新設**（6項目）

6項目はすべて、自社サービスで実際に起きて直したことだけを書いた。

| 項目 | いつ直したか |
|---|---|
| 決済の通知が1回落ちると、課金されているのに使えない人ができる | 2026-09-16 |
| 画面に出している金額と、実際に請求される額がずれる | 2026-09-17 |
| 「最低6ヶ月」の契約が、7ヶ月目以降も解約できなくなる | 2026-09-16 |
| 書いたページが、誰からも辿れない場所に置かれている | 2026-09-17 |
| アクセス計測の設定ひとつで、公開サイトが全部落ちる | 2026-09-17 |
| 自動更新の契約者に、毎月「もうすぐ終わります」と通知していた | 2026-09-17 |

一般論を書いた瞬間に他社と同じになるので、**起きていないことは書かない**。
検査でも、6件が実際に直したものと対応していることを見ている。
