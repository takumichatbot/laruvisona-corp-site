# Search Console 連携の信頼性

Search Consoleの保存・取得経路を次の契約へ揃えた。

- 選択できるのは、連携したGoogleアカウントからその時点で取得できたプロパティとの完全一致だけ。
- OAuthの `invalid_grant` だけを連携失効として扱う。Googleの一時障害、タイムアウト、壊れた応答でrefresh tokenを削除しない。
- プロパティ一覧と検索実績の各APIはHTTP状態、JSONの形、12秒以下の待ち時間を検査する。取得失敗をクリック0件として表示しない。
- プロパティがGoogle側から無くなった場合は、保存値を勝手に別プロパティへ切り替えず、再選択を求める。
- 保存・解除・OAuthコールバックはDBの更新が実際に1件だった場合だけ成功にする。画面もAPI失敗後に「未連携」へ変えない。
- 設定本文は2KiB、URLは500文字まで。

実GoogleアカウントでのOAuth同意、プロパティ選択、検索実績取得は本番資格情報を使う結合試験として残る。ローカル回帰では成功、失効、一時障害、異常応答を差し替えたfetchで区別している。
