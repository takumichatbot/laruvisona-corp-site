# 必要な素材の一覧 — 2026-09-11（Codexの確定を反映）

Higgsfield へ渡すための表。**画面を先に作ってあるので、この表は実際の画面の
どの位置に入るかで書いてある。** 番号は提出したプレビュー画像の番号と対応する。

実装は素材が無くても成立する状態で進めてある（下地・プレースホルダで動く）。
届いたら差し替えるだけ。素材待ちで止まっている作業は無い。

共通の決めごと:

- **画像・動画に文字を焼き込まない。** 見出し・ボタン・料金・製品UIはすべてHTMLで置く。
  焼き込むと、直せない・翻訳できない・読み上げできない・スマホで潰れる。
- 動画は**静止画（poster）を必ず一緒に**。静止画だけでページが成立する。
- 動画は無音・ループ・繋ぎ目が分からないこと（ループの成立は実物に入れて確かめる）。
- 生成画像・生成動画は、実在の店舗の撮影・施術実績として扱わない。画面にもそう書く。

## 1. 会社トップの主役ビジュアル（最優先・未着／条件は確定）

プレビュー **03（PC初回）/ 05（スマホ）** の、見出しの右にある箱。
いまはCSSで描いた抽象的な下地が出ている。

| 項目 | 値 |
|---|---|
| 置き場所 | `public/brand/hero.jpg` ＋ `public/brand/hero.mp4` |
| 差し替え箇所 | `components/BrandVisual.tsx` の `BRAND_VISUAL` |
| 用途 | 会社トップの最初の画面。見出しの右（スマホでは見出しの下） |
| 比率 | PC 16:10 / スマホ 4:3 |
| 寸法 | 1920×1200px 以上 |
| **構図** | 深いネイビーの画面の中に、**輪郭が読める精密な模型状の主役**を1つ。抑えた青と、温かい白の面。明暗差をはっきり付けて、形が潰れないようにする |
| **色** | 地は深いネイビー〜ほぼ黒（`#070e18`〜`#0b1524`）。差し色は抑えた青（`#0ea5e9` / `#0e7490`）。発光の強い表現・SF調・ロボットの顔は不要 |
| **中身** | 事業に必要な仕組みが、部品として組み上がっていく抽象表現。実在の道具・人物・ロゴは出さない |
| **切り出し** | 同じ元画像からPC・スマホの両方を切って成立するのが望ましい。成立しない場合は、**同じデザインの別構図**を作ってよい |
| **文字を置く場所** | なし（見出しとボタンはHTMLで左の列に置く）。「左上3割を必ず空ける」条件は**外した** |
| **外す帯（両方の切り出しで）** | 右下 120×48px。停止ボタンが出るので、主要被写体と重ねない |
| **順番** | **静止画を先に出す。** 完成を確認してから、同じ絵で動画へ進む |
| **動画の動き** | ゆっくり。部品が寄って一つになり、また静かにほどける往復。カメラは止めたまま、被写体だけが動く。フラッシュ・急な明滅・速いカット割りは不可 |
| 尺 | 6〜8秒・ループ・無音 |
| してはいけないこと | 製品画面・グラフ・ロゴ・文字・UI部品を描き込まない（実画面はこちらで撮る） |

素材が無いあいだは、CSSで描いた抽象的な下地が出る。レイアウトと動きは同じ。
