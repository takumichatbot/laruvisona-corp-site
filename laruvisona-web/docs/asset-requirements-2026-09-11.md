# 必要な素材の一覧 — 2026-09-11

Higgsfield 側の納品と突き合わせるための表。実装は素材が無くても成立する状態で
進めてある（下地・プレースホルダで動く）。届いたら差し替えるだけ。

共通の決めごと:

- **画像・動画に文字を焼き込まない。** 見出し・ボタン・料金・製品UIはすべてHTMLで置く。
  焼き込むと、直せない・翻訳できない・読み上げできない・スマホで潰れる。
- **安全域**（下の表の「文字を置く場所」）には、主要な被写体を置かない。
  そこにHTMLの見出しやボタンが重なる。
- 動画は**静止画（poster）を必ず一緒に**。静止画だけでページが成立する。
- 生成画像・生成動画は、実在の店舗の撮影・施術実績として扱わない。公開面にその旨を書く。

## 2. 会社トップの主役ビジュアル（未着）

| 項目 | 値 |
|---|---|
| 置き場所 | `public/brand/hero.jpg`（+ 任意で `public/brand/hero.mp4`） |
| 差し替え箇所 | `components/BrandVisual.tsx` の `BRAND_VISUAL` |
| 用途 | 会社トップの最初の画面、見出しの右（スマホでは見出しの下） |
| 比率 | パソコン 16:10 / スマホ 4:3（同じ画像を切って使う） |
| 寸法 | 1920×1200px 以上 |
| 尺（動画） | 6〜8秒・ループ・無音 |
| 文字を置く場所 | なし（見出しとボタンは左の列。ビジュアルの中に文字は入れない） |
| 主要被写体を外す帯 | 右下 120×48px（停止ボタン）、左右端 6%（切り取りで消える） |
| 色 | 深いネイビー／インクを地に、抑えた青とシアン。発光の強い表現・ロボットの顔は不要 |
| 中身 | 事業に必要な仕組みが組み上がって、つながっていく抽象表現 |
| してはいけないこと | 製品画面・グラフ・ロゴ・文字を描き込まない（実画面はこちらで撮る） |

素材が無いあいだは、CSSで描いた抽象的な下地が出る。レイアウトと動きは同じ。
