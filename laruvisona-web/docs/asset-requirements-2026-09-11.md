# 必要な素材の一覧 — 2026-09-11

Higgsfield へ渡すための表。**画面を先に作ってあるので、この表は実際の画面の
どの位置に入るかで書いてある。** 番号は提出したプレビュー画像の番号と対応する。

実装は素材が無くても成立する状態で進めてある（下地・プレースホルダで動く）。
届いたら差し替えるだけ。素材待ちで止まっている作業は無い。

共通の決めごと:

- **画像・動画に文字を焼き込まない。** 見出し・ボタン・料金・製品UIはすべてHTMLで置く。
  焼き込むと、直せない・翻訳できない・読み上げできない・スマホで潰れる。
- **安全域**（表の「文字を置く場所」）には主要な被写体を置かない。そこにHTMLが重なる。
- 動画は**静止画（poster）を必ず一緒に**。静止画だけでページが成立する。
- 動画は無音・ループ・繋ぎ目が分からないこと（頭と尻が同じ絵で終わる）。
- 生成画像・生成動画は、実在の店舗の撮影・施術実績として扱わない。
- 縦横それぞれ **同じ元素材から切って**使う。PC用とスマホ用を別に作らない。

## 1. 会社トップの主役ビジュアル（最優先・未着）

プレビュー **03（PC初回）/ 05（スマホ）** の、見出しの右にある箱。
いまはCSSで描いた抽象的な下地が出ている。

| 項目 | 値 |
|---|---|
| 置き場所 | `public/brand/hero.jpg` ＋ `public/brand/hero.mp4` |
| 差し替え箇所 | `components/BrandVisual.tsx` の `BRAND_VISUAL` |
| 用途 | 会社トップの最初の画面。見出しの右（スマホでは見出しの下） |
| 比率 | PC 16:10 / スマホ 4:3（**同じ絵を切る**） |
| 寸法 | 1920×1200px 以上 |
| **構図** | 画面の**中央から右下**に主役の塊を置き、**左上3割は暗く空けておく**。スマホで上下を切ったときに主役が残るよう、上下に各10%の余白を持つ |
| **色** | 地は深いネイビー〜ほぼ黒（`#070e18`〜`#0b1524`）。差し色は抑えた青とシアン（`#0ea5e9`／`#0e7490`）。発光の強い表現・SF調・ロボットの顔は不要 |
| **中身** | 事業に必要な仕組みが、部品として集まり、線でつながっていく抽象表現。実在の道具・人物・ロゴは出さない |
| **動画の動き** | ゆっくり。部品が少しずつ寄って一つになり、また静かにほどける往復。カメラは止めたまま、被写体だけが動く。フラッシュ・急な明滅・速いカット割りは不可 |
| 尺 | 6〜8秒・ループ・無音 |
| 文字を置く場所 | **なし**（見出しとボタンは左の列。ビジュアルの中に文字は入れない） |
| 主要被写体を外す帯 | 右下 120×48px（停止ボタン）、左右端 各6%（切り取りで消える） |
| してはいけないこと | 製品画面・グラフ・ロゴ・文字・UI部品を描き込まない（実画面はこちらで撮る） |
