# 公開サイトの視覚言語を統一する

## 問題

業種テンプレートの特徴・サービス、商品画像がない場合、会員表示、フォーム完了、予約完了、チャット入口に端末依存の絵文字が混ざっていた。フォントやOSで造形が変わり、顧客が選んだ書体と配色にも合わなかった。

## 変更

- 特徴とサービスの既定絵文字を、差し色に連動する `01` 形式の小さな連番へ置換する。
- 顧客が入力した短い文字記号は残す。
- 商品画像なし、会員限定、購入・送信・予約完了、カレンダー、チャット入口を日本語の表示へ統一する。
- `EXPORT_VERSION` を 15 から 16 に更新する。保存済みHTMLの一括再生成は行わない。

## 検証

`tests/public-visual-language.test.ts` で公開HTMLの各経路と購入完了表示を検査する。
