## 2. 案内ページのデモで、何を変えたか

### 決めたこと

**選ぶのは「見せ方」だけ。3つ。**
以前は「雰囲気5つ・書体3つ・画面2つ」が並んでいた。どれを押せばいいのか
分からないので、**操作を1種類に絞った**。書体は見せ方に含めた（「上質」なら明朝）。
画面のパソコン／スマホは、見ている画面の幅で自動で切り替わる。

選べる3つは、**制作画面の「雰囲気を選び直す」と同じ `DESIGN_PRESETS`**。
デモ専用の設定体系は作っていない。ここで見た見え方は、顧客が制作画面で
そのまま選べる。

| 見せ方 | 中身（設定そのもの） |
|---|---|
| 上質（最初） | 明朝・余白ひろめ・ボタンは角のまま（見本の作品で採用しているもの） |
| 落ち着いた | ゴシック・余白ふつう・ボタンはすこし丸い |
| やわらかい | 丸ゴシック・余白ふつう・ボタンはまるい |

**最初から完成例を出す。** 以前は「ばらばら」から始めていた。
先に到達できる品質を見せ、**選んだあとに組み上がる**順にした。
「ばらす／組み上げる」は、いつでも押し直せる。

### 白い画面を挟まない（入れ替えのやり方）

見せ方を押すたびに作り直すが、**前の画面は消さない**。
入れ物を2つ持ち、裏で新しい方を作り、文字と写真がそろってから入れ替える。

```
押す → 裏の入れ物に新しいHTML（世代番号つき）
     → 中から「描き終わった」
     → いちばん新しい世代なら、表に出す（0.3秒でなじませる）
     → 古い方は外す（キーボードで入り込めないように）
```

**連続で押しても、古い方の描き終わりが最後の選択を上書きしない。**
作るたびに世代番号を振り、いま最後に押されたものだけを採る。
`data-lhp-demo-picked` / `-shown` / `-busy` を外から読めるようにしてあり、
検査はこれで「4回続けて押して、最後のものが残るか」を見ている。

> 途中で1度、**表に出ている入れ物を消してしまう不具合**を検査が捕まえた。
> 原因は、押したときの判断が古い値（描き直し前の状態）を見ていたこと。
> いまは、どちらを見せているか・中身は何かを ref でも持ち、
> 外すときも「そのあいだに次の選択が使っていないか」を確かめている。

### 触り心地

- 選択状態: `role="radiogroup"` / `role="radio"` / `aria-checked`。押した瞬間に選択が移る
- 更新中: 押した札に「作り直しています…」、枠の上に細い帯、読み上げにも `role="status"` で伝える
- フォーカス: 枠線がはっきり出る。選ばれていないものは Tab の順路から外す
- キーボード: 矢印キーで移動、Home / End。ラジオボタンと同じ動き
- 動きを減らす設定: 組み上がる演出を省いて、選んだ完成状態を直接出す（検査で、押しても `--e` が 1 にならないことを確認）

### 申込と、見本の予約の区別

- 枠の中に「見本：架空の美容室のサイト」の札を常に出す（枠から離さない）
- 予約フォームは「このお店の予約フォームまで試す」を押したときだけ開く
- 開く前も開いたあとも「見本のお店の予約です。LARU HP のお申し込みではありません」を出す
- 送信はその場で受け止め、**どこへも送らない**。検査で `/api/` への送信が0件であることを見ている

### 保存APIを呼ばない

見せ方の選択は、この画面の中の状態だけ。顧客データの保存は呼ばない。
単体（`fetch('/api` が無いこと）と、実ブラウザ（POSTが0件）の両方で見ている。

## 3. 会社トップの主役ビジュアル

採用: `atelier-nano-requested-pro-original.png`（4800×3584・23MB）。
納品資料は `LARU-Brain/atelier-comparison-20260911-8e2c7e9b/納品とレビュー.md`。

### 合成そのままにしなかったところ

| 納品時の合成 | いまの実装 |
|---|---|
| 全体を contain し、下に64px空ける | **固定要件にしない**。切り抜きを詰めて主役を大きくした |
| 停止ボタンを描いていた | **静止画だけの段階では出さない**（動画が動くときだけ出る） |
| 画像の地とページの地に段差 | 書き出しの段階で、**地だけをページの地色へなじませた** |
| PC・スマホとも同じ原画 | **別々に切り抜いた**。枠の縦横比を切り抜きと同じにしてあるので、cover でも切れない |
| 原画PNG | avif / webp / jpg を表示寸法ぶんだけ（いちばん重い jpg で53KB、実際に選ばれるのは avif 7KB） |

### 地のなじませ方（`scripts/brand-hero.mjs`）

原画の地は濃紺だが、左下の床が明るく、ページの地色 `#070e18` と差がある。
そのまま四角く置くと、その差が「枠の線」に見える。

明るさから**被写体の面**を作り、**被写体は触らずに、地だけ**を外側へ向けて
ページの地色へ寄せている（短辺の24%）。被写体の輪郭は暗くならない。
`BrandVisual` 側も、枠線・角丸・地色を持たないようにした。

検査は、画像の上辺をまたぐ帯を実際に撮って、すぐ上（ページ）とすぐ下（画像）の
画素を比べている。**差はPC・スマホとも 0〜2（256階調）**。
